# 🏭 Симулятор производства ЦБП

Интерактивная визуализация полного технологического цикла целлюлозно-бумажного комбината.

## 📦 Что это?

Веб-приложение, демонстрирующее 12 этапов производства бумаги — от заготовки древесины до лесовосстановления. Каждый этап представлен карточкой с изображением и подробной информацией.

## 🚀 Быстрый запуск

### Вариант 1: Открыть файл напрямую
1. Откройте папку `dist/`
2. Дважды кликните на `index.html`
3. Приложение откроется в браузере

**Всё!** Не нужны серверы, Node.js или другие программы.

### Вариант 2: Запустить локально
```bash
npm install
npm run dev
```
Откройте http://localhost:3000

### Вариант 3: Развернуть на GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите файл `dist/index.html` в корень
3. Включите GitHub Pages в настройках репозитория
4. Получите ссылку вида `https://username.github.io/repo-name/`

## 📋 12 этапов производства

1. 🪓 **Лесозаготовка** — валка деревьев, трелёвка, транспортировка
2. 🌲 **Подготовка сырья** — окорка, рубка щепы, сортировка
3. 🔥 **Варка целлюлозы** — сульфатная варка в котлах
4. 💧 **Промывка** — удаление чёрного щёлока
5. ✨ **Отбелка** — ECF/TCF технологии
6. ⚙️ **Размол** — подготовка бумажной массы
7. 📄 **Формование** — сеточный стол БДМ
8. 🌡️ **Сушка** — сушильные цилиндры
9. 📦 **Накатка** — каландрирование, рулоны
10. 📋 **Пачки А4** — упаковка SvetoCopy (ярко-зелёная)
11. 🚚 **Склад** — хранение и отгрузка
12. 🌱 **Лесовосстановление** — высадка саженцев

## 🎨 Особенности

- **Single-file HTML** — весь проект в одном файле (215 KB)
- **AI-генерированные изображения** — полуреалистичный стиль
- **Интерактивность** — клик по карточке открывает детальную информацию
- **Адаптивный дизайн** — работает на ПК, планшетах, телефонах
- **Бренд SvetoCopy** — фирменный зелёный цвет (#22C55E)
